# Skills across harnesses

Taskrunner's skills reach Claude Code, Codex and Hermes; the user's own skills are
linked by `taskrunner sync`; and a role such as a librarian ships as a skill rather
than an agent, with its model chosen by a worker. Discussed from 2026-09-13
(`eae896a`), shipped in `13d6d01` (2026-09-14) and `834bdb2` (2026-09-15).

harnesses" section, later "Agents across harnesses", retired into this archive.
